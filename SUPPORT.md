# Support

Before reporting a problem, record the Skunkworks version, game API version,
operating system, focused probe, execution mode, and the exact time of the
failure. Check Settings → Refresh Diagnostics and the planner's waiting reason.

For refresh, dispatch, or persistence problems, include the displayed stage
timings and database health summary. Do not post API keys. Inspect diagnostic
logs and snapshots before sharing them because they may contain game account
names, messages, coordinates, and inventory.

Feature requests and reproducible defects belong in the release repository's
issue tracker. They may also be sent to **@Ziegenbagel** on the Von Neumann Game
Discord or **ziegenbagel.gaming@gmail.com**. Security reports follow
[SECURITY.md](SECURITY.md). The Von
Neumann Game service and its API are maintained separately; server outages or
account problems may need to be reported to that project.

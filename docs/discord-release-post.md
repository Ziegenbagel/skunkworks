## SKUNKWORKS v1.0.0 — Mission Control for Von Neumann Game

Skunkworks is a free, open-source fleet-management companion for macOS, Windows, and Linux.

**Highlights**
• Live fleet, resources, production, communications, navigation, and persistent 3D galaxy map
• Manual travel, scanning, crafting, mining, repair, cargo, transfers, SCUT, and infrastructure controls
• Prioritized targets with explainable waiting reasons
• Observe Only, Require Approval, and Automatic modes
• Command allowlists, live validation, safety checks, emergency stop, history, and diagnostics

**Download, source, and instructions**
https://github.com/Ziegenbagel/skunkworks/releases/latest

Packages are unsigned, so your OS may warn you. Download only from this GitHub release.

**Safe first launch**
1. Enter your API key; it is stored in your OS credential vault.
2. Test the connection and verify the correct account and focused probe.
3. Stay in **Observe Only** during the first refresh.
4. Review each probe's targets, priorities, resource/fuel/capacity floors, safety, role, and routes.
5. Review proposed commands, then try **Require Approval** before Automatic.
6. Before Automatic, enable only intended commands, verify **Allow Skunkworks to Send Game Orders**, and set a conservative order limit.

Automatic mode sends real orders. Read warnings, verify network/API status, and remember the red **STOP** control.
